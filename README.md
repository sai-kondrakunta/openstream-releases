# OpenStream releases

Install files (APKs) for OpenStream, an Android TV app for Jellyfin. This repository holds releases only, no source.

- Download the latest `app-full-universal-release.apk` from **Releases** (works on any Android TV).
- Already installed? The app updates itself from here and keeps your logins and settings.

OpenStream is based on [Nuvio](https://github.com/NuvioMedia/NuvioTV) and is licensed under the GPL v3.
The source code is available on request.
